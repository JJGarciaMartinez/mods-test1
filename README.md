# Mods-test1

Modpack de Minecraft publicado con HopSync.

**Para jugarlo**: abre HopSync, pulsa «Añadir pack» y pega este enlace:

```
https://github.com/JJGarciaMartinez/mods-test1/releases/download/hopsync/manifest.json
```

HopSync instala los mods y los configs en la carpeta del juego que elijas y los mantiene al día.

Este repositorio lo mantiene HopSync: el pack se edita y se publica desde la app, y lo que se cambie aquí a mano se sustituye en la siguiente publicación.

Los mods de este pack son obra de sus autores y se rigen por sus propias licencias. Los que vienen de Modrinth se bajan directamente de Modrinth. Los archivos de `local-mods/` y `configs/` los aportó quien publica el pack, que es quien responde de tener permiso para compartirlos.
